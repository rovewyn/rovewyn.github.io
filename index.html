      Code rule

      The encoder uses 16 positions, from 0 to 15. The direction is forward (+1) or backward (−1). The offset is a fixed number from 0 to 15.

      code = direction × position + offset
      If the result is below 0, add 16. If the result is above 15, subtract 16. Repeat until the result is from 0 to 15.
